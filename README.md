# Clean Passport Photo Studio (Web & Mobile APK)

A biometric passport photo preparation studio for web and Android, styled with the sleek dark aesthetics of the Clean Voice Recorder app.

![App Icon](icon.png)

## What's New

1. **Ergonomic Layout for Real-Time Adjustments**:
   - **Passport Standard & Photo Source** at the top.
   - **Line Instructions & Biometric Alignment Guides** clearly positioned directly above the preview window.
   - **Preview Window** positioned *above* the adjustment sliders so your hands or sliders never obscure the live preview while scaling, adjusting brightness, or rotating.
   - **Adjustment Bars (Scale, Brightness, Re-center, Rotate)** directly beneath the preview.
   - **Print Sheet Export** with 300 DPI high-resolution output.

2. **4 mm Shaded Guide Lines (30 mm Biometric Distance)**:
   - **4 mm Wide Shaded Bands**: Prominent 4 mm shaded guide bands across the preview frame for clear visibility.
   - **30 mm Biometric Distance**: Evenly centered vertically (`±15 mm` from center) according to official passport specifications.
   - **Upper Band**: `HEAD TOP` guide with 30 mm measurement scale.
   - **Lower Band**: `CHIN` guide.
   - **Center Line**: Vertical dashed line for nose and eye alignment.
   - **Toggle Control**: Quickly show or hide guides with the "Guides: On/Off" button.

3. **App Name & Official 3D Icon**:
   - Renamed to **Clean Passport Photo Studio**.
   - Custom 3D gradient camera app icon with soft violet glow integrated across all Android mipmap densities and web interface.

4. **Android APK Ready**:
   - **Root APK**: [CleanPassportPhotoStudio.apk](file:///c:/Users/ezsha/Github/Passport%20photo%20creator/CleanPassportPhotoStudio.apk) (6.2 MB)
   - Integrated with Android `MediaStore`: generated print sheets save directly to the device's **Pictures / PassportPhotos** gallery with a native toast notification.

## Installing on Android

Install directly to a connected Android phone:
```bash
adb install CleanPassportPhotoStudio.apk
```
Or transfer `CleanPassportPhotoStudio.apk` to your phone via USB, Drive, or file transfer and tap to install.
